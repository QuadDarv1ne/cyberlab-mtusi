## О проекте

**CyberLab v2** — образовательная платформа МТУСИ (кафедра информационной безопасности) для проведения лабораторных работ по дисциплине «Защита информации от вредоносного ПО». Платформа объединяет каталог лабораторных работ с фильтрацией и поиском, систему CTF-флагов с баллами и подсказками, дашборд с графиками прогресса (BarChart, PieChart через recharts), справочник из 10 инструментов кибербезопасности, ленту последних отправок флагов и систему отслеживания прогресса студентов.

Платформа поддерживает 5 лабораторных работ: OSINT и сбор информации, тестирование на проникновение, защита баз данных от SQL-инъекций, аудит веб-ресурсов, ARP/DNS-spoofing.

## Что нового в v2

- **Фильтры в каталоге** — фильтрация по категориям (OSINT, эксплуатация, веб, сеть) и уровню сложности
- **Поиск по каталогу** — мгновенный поиск по названию и описанию лабораторной работы
- **Вкладка «О проекте»** — подробная информация о разработчике, университете МТУСИ, технологическом стеке
- **Графики на дашборде** — BarChart баллов по каждой ЛР и PieChart распределения статуса выполнения (recharts)
- **Лента последних отправок** — 10 последних попыток отправки флагов с указанием студента, ЛР и результата
- **Анимации** — плавные переходы между вкладками, анимация появления карточек через Framer Motion
- **Тёмная тема** — полное переключение темы с сохранением в localStorage
- **Пустые состояния** — информативные сообщения при отсутствии данных в таблицах и списках
- **Улучшенный футер** — указание разработчика Дуплей Максим Игоревич

## Система CTF-флагов

- Формат флагов: `CYBER{...}`
- Каждая лабораторная содержит 3–4 флага
- Стоимость каждого флага: 10–20 баллов в зависимости от сложности
- Доступны подсказки для каждого флага
- Прогресс сохраняется в базе данных
- Поддерживается несколько студентов с индивидуальным прогрессом
- Всего: 16 флагов по 5 лабораторным работам

## Установка и запуск

### Предварительные требования

- **Node.js** версии 18 или выше (рекомендуется 20+)
- **npm**, **bun** или **yarn** в качестве пакетного менеджера

### Шаги установки

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/cyberlab.git
cd cyberlab

# 2. Установить зависимости
npm install
# или
bun install

# 3. Сгенерировать клиент Prisma
npx prisma generate

# 4. Применить схему к базе данных
npx prisma db push

# 5. Заполнить начальными данными
npx prisma db seed

# 6. Запустить в режиме разработки
npm run dev
# или
bun dev

# 7. Открыть в браузере
# http://localhost:3000
```

### Сборка для продакшена

```bash
npm run build
npm run start
```

## База данных

По умолчанию используется SQLite (файл `db/custom.db`). Схема БД включает 5 моделей:

| Модель | Описание |
|--------|----------|
| **Student** | Студент с ФИО, группой, баллами |
| **Lab** | Лабораторная работа с описанием, категорией, сложностью |
| **LabFlag** | Флаг лабораторной с ключом, стоимостью, подсказкой |
| **LabProgress** | Прогресс студента по лабораторной работе |
| **FlagSubmission** | Попытка отправки флага студентом |

Команды для работы с БД:

```bash
npm run db:generate  # Сгенерировать клиент Prisma
npm run db:push      # Применить схему к БД
npm run db:migrate   # Создать и применить миграцию
npm run db:reset     # Сбросить БД
```
